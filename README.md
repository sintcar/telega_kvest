# Quest Telegram Bot

Бот с викториной/квестом для Telegram-группы с веб-админкой.

## Возможности

- Постинг заранее подготовленных вопросов по таймеру в группу
- Варианты ответов (кнопки)
- Фиксация:
  - правильности ответа
  - времени ответа (от момента появления вопроса)
  - количества неверных попыток
- Рейтинг пользователей по суммарным очкам
- Новый пользователь может отвечать на **старые** вопросы и участвовать в общем рейтинге
- Простая веб-админка:
  - вход по паролю
  - управление вопросами
  - просмотр рейтинга и пользователей

## Быстрый запуск

1. Установите зависимости (Python 3.10+):

   ```bash
   pip install -r requirements.txt
   ```

2. Создайте `.env` из примера:

   ```bash
   cp .env.example .env
   ```

   Заполните:
   - `BOT_TOKEN` — токен вашего бота
   - `ADMIN_PASSWORD` — пароль для входа в админку
   - `SECRET_KEY` — любая случайная строка (для сессий)
   - `GROUP_CHAT_ID` — ID вашей группы (отрицательное число, наподобие `-1001234567890`)

3. Прогрейте базу (создаст таблицы) — они создаются автоматически при первом запуске бота или админки.

4. Запуск бота:

   ```bash
   python run_bot.py
   ```

5. Запуск админки (по умолчанию на `http://0.0.0.0:8000`):

   ```bash
   python run_admin.py
   ```

6. Настройте вебхуки **или** используйте long polling:
   - В этом примере используется **long polling**, так что можно просто оставить `run_bot.py` запущенным.

## Как получить ID группы

1. Добавьте бота в группу.
2. Дайте боту право читать переписку.
3. Напишите что-нибудь в группе.
4. Включите режим "логирования" у любого бота, который показывает chat_id (например, @RawDataBot) **или** используйте свой небольшой скрипт.
5. Скопируйте `chat_id` и впишите в `.env` как `GROUP_CHAT_ID`.

## Модель начисления очков

Для каждого вопроса:

- Берётся **первая правильная** попытка пользователя.
- Считается время ответа `t` в секундах от момента публикации вопроса.
- Количество неправильных попыток до первой правильной — `w`.
- Очки:

  ```text
  base = 1000
  penalty_time = t
  penalty_wrong = w * 150
  score = max(50, base - penalty_time - penalty_wrong)
  ```

Если у пользователя нет правильного ответа на вопрос — он получает 0 очков за этот вопрос.

Итоговый рейтинг пользователя — сумма очков за все вопросы.

## Вход в админку

По умолчанию админка доступна по адресу:

- `http://localhost:8000/`

Логин:
- в браузере откройте `/login`
- введите `ADMIN_PASSWORD` (из `.env`)

После этого станут доступны:
- список вопросов и создание новых
- просмотр пользователей
- рейтинг
